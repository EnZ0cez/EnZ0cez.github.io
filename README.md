# Enze Chen

深圳大学计算机与软件学院，导师 [Philippe Fournier-Viger](https://www.philippe-fournier-viger.com/) 教授。

我的研究方向是数据挖掘与模式挖掘，主要围绕最小描述长度（MDL）原理做项集挖掘：怎样从大规模数据里挑出一组紧凑、有代表性、能高效压缩数据的模式。这个站点是我的个人主页，也放着我做研究过程中积累的论文、课程和编程笔记。

## Research Interests

- Pattern Mining / Itemset Mining
- Minimum Description Length (MDL)
- Heuristic Optimization（模拟退火、爬山法）
- Data Mining

## Publication

**HMP: Efficient Heuristic Algorithms for MDL-Based Itemset Mining**

Enze Chen, Muhammad Zohaib Nawaz, M. Saqib Nawaz, Philippe Fournier-Viger

*Applied Soft Computing*, Volume 187, Article 114314, February 2026

HMP 提出两个启发式算法 HMP-Sa（模拟退火）和 HMP-Hc（爬山法）做基于 MDL 的模式选择，在运行时间和压缩率上都优于 GRIMP、KRIMP 和 SLIM。

[论文详情与 BibTeX](Papers/HMP.md) · [DOI: 10.1016/j.asoc.2025.114314](https://doi.org/10.1016/j.asoc.2025.114314)
