# AI Agent项目计划

## 项目概述
创建一个AI Agent，使用OpenAI API和Langchain，实现以下功能：
1. 从输入的博主ID列表获取B站UID和微博ID
2. 获取这些博主的动态内容
3. 根据动态内容总结博主近期的线下行程

## 技术栈
- Python
- Langchain
- OpenAI API
- 已有的微博动态获取代码
- B站动态获取功能（需要开发）

## 功能模块
1. 博主ID管理模块
2. B站动态获取模块
3. 微博动态获取模块（复用现有代码）
4. AI分析和总结模块
5. 主控制流程

## 开发步骤
1. 搭建项目结构
2. 实现B站动态获取功能
3. 集成微博动态获取功能
4. 实现AI分析和总结功能
5. 构建主控制流程
6. 测试和优化
